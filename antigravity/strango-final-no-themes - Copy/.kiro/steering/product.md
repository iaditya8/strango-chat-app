# Product Overview

**Strango** is an anonymous voice and text chat application that connects strangers from around the world for real-time conversations.

## Core Features
- **Simple Matching**: Users are paired based on country and gender preferences
- **Voice & Text Chat**: Real-time WebRTC voice communication with text chat backup
- **Smart Matchmaking**: Country-priority algorithm with timezone optimization
- **Bidirectional Reconnection System**: Both users can reconnect after accidental disconnects (60-second window)
- **Conversation Starters**: Random conversation prompts to break the ice
- **Quick Messages**: Pre-defined message buttons for easy interaction
- **Safety Features**: Report, block, and abuse protection systems
- **Skip Protection**: Rate limiting to prevent excessive partner skipping

## User Flow
1. Landing page with age verification and terms acceptance
2. Set simple preferences (name, country, gender)
3. Get matched with compatible stranger using country and timezone priority
4. Receive random conversation starter to help break the ice
5. Voice/text chat with quick message options and real-time features
6. If disconnected, automatic reconnection attempt (both users can reconnect within 60 seconds)
7. Option to skip to next partner or end session

## Key Differentiators
- **Bidirectional Reconnection**: Both users can reconnect after accidental disconnects - fully symmetric system
- **Simplified Matching**: Focus on essential preferences (country, gender) for faster connections
- **Conversation Assistance**: Built-in conversation starters and quick messages
- **Time-optimized Matching**: Considers timezone for better conversation timing
- **Comprehensive Safety**: Multi-layered abuse prevention and moderation tools
- **Clean, Modern UI**: Mobile-responsive design with intuitive interactions
- **Global Reach**: Support for 50+ countries with flag emojis
